## Промпт для banner.png

Для Midjourney / DALL·E / Recraft / Ideogram. Размер 1200×400 (или 3:1), тёмный фон.

> Wide minimalist tech banner, 1200x400, dark background (#0d1117 GitHub-dark), subtle grid.
> Center-left: glowing purple Obsidian-style crystal/vault icon. Three thin neon connection
> lines flow from a small Telegram paper-plane glyph (top) into three rounded cards labelled
> by color — green (tasks/kanban), blue (knowledge/notes), amber (finance/coins). Lines
> continue down into a folder/database icon (the vault). On the right, two laptop/server
> silhouettes connected by a dashed sync arrow (Mac ↔ VPS). Flat vector, clean line-art,
> soft neon glow, generous negative space, no text, no logos, no faces. Color palette:
> #0d1117 background, #58a6ff blue, #3fb950 green, #d29922 amber, #bc8cff purple, #8b949e grey.

Негатив-промпт (если поддерживается): `text, watermark, logo, faces, people, clutter, photorealistic, 3d render`.

Альтернатива: можно отрисовать баннер из `architecture.svg`, упростив до трёх цветных карточек + Telegram + vault.
