# Product demo assets

Goal: a **15-second** loop strangers understand without reading the monorepo.

```text
Telegram → confirm → Obsidian file → dashboard chart
```

## What’s here

| File | Role |
|------|------|
| `demo.gif` | README hero loop (Telegram demo) |
| `storyboard.png` | Fallback still (GitHub-safe) |
| `storyboard.svg` | Source vector |

`demo.gif` is compressed for GitHub (~8MB, 720p). Source capture may live outside the repo; see [docs/DEMO_CAPTURE.md](../../docs/DEMO_CAPTURE.md).

## Rules

- No real names, employers, balances, phone numbers, or city-identifying paths
- Prefer English UI for OSS screenshots (`AGENT_LOCALE=en`)
- Crop Telegram to the bot thread only
