# Product demo assets

Goal: a **15-second** loop strangers understand without reading the monorepo.

```text
Telegram → confirm → Obsidian file → dashboard chart
```

## What’s here

| File | Role |
|------|------|
| `storyboard.svg` | Static storyboard (safe to commit; no PII) |
| `demo.gif` | Optional — add after you capture (see docs) |

Until `demo.gif` exists, README links this folder + [docs/DEMO_CAPTURE.md](../../docs/DEMO_CAPTURE.md).

## Rules

- No real names, employers, balances, phone numbers, or city-identifying paths
- Prefer English UI for OSS screenshots (`AGENT_LOCALE=en`)
- Crop Telegram to the bot thread only
