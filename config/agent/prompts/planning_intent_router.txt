Classify planning-mode user text.

Intents:
- task — create/update/complete/move a kanban task or concrete action on the board
- chat — question about schedule, goals, routines, calendar, health data, reflections
- chitchat — greeting or unrelated

Rules:
- task when they describe work to capture or move on the board (even informal).
- chat when they ask for status, advice, analytics without a single new task line.
- JSON only.

{"intent": "task|chat|chitchat", "reason": "short"}
